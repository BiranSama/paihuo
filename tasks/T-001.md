## 目标

仓库里有一个能在 Windows 上启动的空壳：打开桌面应用，它启动内核进程，界面连上内核并显示
内核返回的版本号；关闭窗口后内核继续运行，从托盘退出才停。

这张卡同时验证 ADR-0003 最大的风险：Tauri 外壳能否稳定地启动、守护并打包一个 TypeScript 内核。

## 要做的事

1. 建立 pnpm 工作区和 `apps/desktop`、`packages/shared`、`packages/core` 三个包。
2. 选定格式化与静态检查工具并配置；在 PR 里说明选择。
3. 内核：启动时在本机回环地址上监听一个随机端口，只接受带正确令牌的连接，实现 `system.info`。
4. 外壳：启动时生成令牌并启动内核，把端口和令牌交给界面；内核意外退出时重启它并提示。
5. 窗口关闭时隐藏到托盘，内核继续；托盘菜单"退出"时停止内核再退出。
6. 界面：一个页面，显示连接状态和 `system.info` 的结果。
7. 持续集成：在 Windows 上跑安装、检查、测试、构建。
8. 试着打一个 Windows 安装包，记录内核是怎么被打包进去的；打不通就如实记录卡在哪。

## 验收标准

- [ ] 在一台干净的 Windows 11 上按 `README.md` 的步骤能跑起来。验证：照着做一遍并记录。

- [ ] 检查、测试、构建在持续集成里通过。
