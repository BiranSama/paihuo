## 要小心的地方

本机 Git 可能因工作目录所有者不同而提示 `dubious ownership`。确认身处本项目根目录后，PowerShell 可用 `git -c "safe.directory=$((Get-Location).Path -replace '\\','/')" status -sb`，仅对本条命令有效。

## 怎样确认状态没问题

在同步后的项目根目录执行 `git branch -vv`，应看到两条分支各自跟踪同名远程。PR 合并后执行 `git fetch origin`，再用 `git ls-tree --name-only origin/main -- tasks/T-001.md` 确认任务卡已经进入默认分支。
