# 交接单

不同 harness、不同模型、不同会话之间靠交接单接力，不靠记忆。规则见 `AGENTS.md` 第 8 节。

- 文件名：`YYYY-MM-DD-HHMM-T-001-from-to.md`。`from`、`to` 写角色加模型或 harness 的简称，
  例如 `worker-codex`、`worker-claude`；不知道谁接手就写 `next`。
- 用 `TEMPLATE.md`。每一栏都要填，没有内容写"无"。
- 写完提交并推送，否则接手方看不到。
- 接手方在底部追加"已接手"，不改上面的内容。
- 交接单只追加，不删除。卡完成后它们留作记录。

写交接单时想象接手方什么背景都没有：它只读过 `AGENTS.md`、`STATUS.md` 和任务卡。
它拿到交接单后应该能在十分钟内继续动手，而不需要重新摸索你已经弄清楚的事。
