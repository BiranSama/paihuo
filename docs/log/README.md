# 留档

每次阶段性改动写一条简报。只讲关键，细节留在 PR 和提交历史里。
改正一个错误也要留档：错在哪、怎么发现的、怎么改的。

- 文件名：`YYYY-MM-DD-NN-short-name.md`。`NN` 是当天的序号，从 01 起。
- 只追加新文件，不改写、不删除已有的简报。写错了就再写一条更正，并指向原来那条。
- 一条简报控制在一屏以内。

## 格式

```
# 标题（一句话说清做了什么）

- 日期：
- 谁：角色 / 模型 / harness
- 关联：任务卡、PR、issue、问题编号

## 做了什么
三行以内。

## 为什么
一两句。改正错误时写：错在哪、怎么发现的。

## 改了哪些
文件或模块，不用列到每一行。

## 结果
怎么验证的，结论是什么。没验证的明说。

## 遗留
还没做的、要注意的。没有就写"无"。
```
