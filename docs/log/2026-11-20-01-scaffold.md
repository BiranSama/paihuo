- 日期：2026-11-20

## 做了什么

建立严格 TypeScript 工作区，Tauri 启动带随机端口和令牌的 Node.js 内核，React 通过本机 WebSocket 显示版本。Windows CI 安装、检查、测试并构建 NSIS。

## 改正与复验

- Windows CI 首次暴露换行差异，补充 Git 行尾规则后通过。Windows 开发启动另发现 Vite 监控 Cargo 链接文件时触发 EBUSY。排除 Rust 目录后，按 README 重跑，窗口显示“已连接”和 0.1.0。
- Rust 生命周期回归覆盖内核就绪后的退出请求。独立评审指出许可遗漏，修复后从 NSIS 解包核对了 Node、ws、5 个前端包、224 个 Rust 依赖和 WebView2 加载器的声明。

## 结果与边界

安装包为 25,704,194 字节，SHA-256 为 `8c9eea224bdb615a7ca725ceb3428f7b40087713a52241bfbf01a049bbe60ed6`。Windows 11 企业版 LTSC 26100 上运行包内应用，终止内核后 4.74 秒首次观察到新 PID，随后检查页面已恢复。关窗后内核存活；合成右键通知打开真实托盘菜单，选择“退出”后壳和核均结束。空闲 8 秒采样的工作集为壳 27.72、核 47.80、单个 WebView2 渲染进程 63.84 MiB。
