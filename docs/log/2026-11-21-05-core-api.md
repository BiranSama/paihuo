## 对界面交付

七个可用命令覆盖成员名册、私聊、分页、投递、工作项、工作详情和系统信息。六个后续命令先校验参数，返回“尚未实现”。请求带 id，事件独立广播。已获准连接的界面在首个成功回包后收到握手期间积压的事件，发送方先收到投递回执。工作详情包含该工作最近的 50 条运行摘要和最近的 50 条中断提示。实际字段见[共享类型](../../packages/shared/src/api.ts)。

普通页默认和上限为 50，额外取一行判断是否有下页。私聊按排他的 seq 双向翻，成员和工作按排他的 ID 升序翻。单帧 1 MiB 可以容纳 50 条各 16 KiB 的普通文本及元数据；UTF-8 或 JSON 转义使一页过大时缩短页面，以实际交付的边界继续。超大正文或展示字段有截断标志，数据库原文保留。单个事件 64 KiB，握手积压最多 128 个事件或 1 MiB；活动连接发送积压超过 2 MiB 则断开。

## 修正与验证

审查发现大列表可能永远超过单帧。已复现 65 项工作与超大单项，改为有界 SQL 游标、逐项展示截断，并检验长主键能续页。另修正握手期间漏审批、超帧的 1009 被提前销毁连接掩盖，以及成员换大脑后旧会话被误拒绝。真实适配器是否就绪按 T-008 持久会话判断。

Windows 本机通过 `pnpm check` 和 89 项 Vitest，其中 14 项为本卡接口用例。实际子进程在隔离数据目录验证读写、令牌管道启动、缺少适配器及 stdin 关闭后释放 SQLite 锁。生产未注册假适配器。界面交互由 T-011 接续，真实运行时由 T-006/T-007 接入。
