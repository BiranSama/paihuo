## 里程碑 M1：在派活里和一位成员说上第一句话

目标是尽早开始自用，不等第 1 期全部做完。M1 只走最薄的一条线：

1. T-015 真实会话验证 → 选定路线
2. T-006 或 T-007 先做一个适配器（哪个先做按 T-015 的结论）
3. T-008 调度 → T-010 内核接口
4. T-011 界面只做私聊的最小版本：成员列表、一段对话、输入框

M1 验收：打开派活，给一位真实成员发一句话，收到回复；关掉窗口再打开，对话还在。
做到这一步后，老板开始每天用它做一件小事，T-009、T-012、T-013 和 T-011 的其余部分在使用中补齐。
M1 之后做一次简短复盘，写进 `docs/retro/`。
